# SuKo website

Static one-page site for SuKo, an EEG-guided sleep pod (in development, Munich).

- `index.html`: the landing page (no build step)
- `assets/`: EEG images and self-hosted fonts (Inter, Space Grotesk; SIL Open Font License)

EEG traces and hypnogram: YASA sample recording, Vallat & Walker (2021), eLife 10:e70092, https://doi.org/10.7554/eLife.70092

## Deploy

Cloudflare Pages, connected to this repository. Framework preset: None. Build command: empty. Output directory: `/`.
